# IMO 2011 Q5

**Problem.** Let `f` be a function from the integers to the positive
integers. Suppose that, for any two integers `m` and `n`, the difference
`f(m) - f(n)` is divisible by `f(m - n)`. Prove that, for all integers `m`
and `n` with `f(m) ≤ f(n)`, `f(m)` divides `f(n)`.

## The solution, in natural language

This is a translation of the proof above, step for step — not a
re-derivation or the different route Mathlib's own human-written
reference proof for this file takes.

**Claim.** For all integers $m, n$ with $f(m) \le f(n)$, we have
$f(m) \mid f(n)$.

**Proof.** Fix $m, n$ with $f(m) \le f(n)$. Either $f(m) = f(n)$ or
$f(m) < f(n)$.

*Case $f(m) = f(n)$.* Then $f(m) \mid f(n)$ trivially, since a number
divides anything equal to itself.

*Case $f(m) < f(n)$.* Apply the divisibility hypothesis twice:

- With $(m, n)$: $f(m-n) \mid f(m) - f(n)$.
- With $(m,\, m-n)$: $f\big(m - (m-n)\big) \mid f(m) - f(m-n)$, and since
  $m - (m-n) = n$, this says $f(n) \mid f(m) - f(m-n)$.

**Bounding $f(m-n)$.** Since $f(m-n)$ divides $f(m)-f(n)$, and
$f(m)<f(n)$ means $f(n)-f(m)$ is a *positive* number that $f(m-n)$ also
divides (dividing $x$ or $-x$ is the same thing), a divisor of a positive
number can be no bigger than that number. So
$$f(m-n) \le f(n) - f(m).$$

**Showing $f(m-n)$ equals $f(m)$ exactly.** Consider the quantity
$f(m) - f(m-n)$. We know $f(n)$ divides it (from the second application
above). We can also bound it strictly between $-f(n)$ and $f(n)$:

- *Upper bound:* since $f(m-n) > 0$, $\; f(m) - f(m-n) < f(m) \le f(n)$.
- *Lower bound:* negate the bound $f(m-n) \le f(n) - f(m)$ derived just
  above to get $-f(m-n) \ge f(m) - f(n)$, then add $f(m)$ to both sides:
  $$f(m) - f(m-n) \ge f(m) - (f(n) - f(m)) = 2f(m) - f(n).$$
  Since $f(m) > 0$, this is itself $> -f(n)$, so
  $f(m) - f(m-n) > -f(n)$.

So $f(m)-f(m-n)$ is a multiple of $f(n)$ lying strictly between $-f(n)$
and $f(n)$ — and the only such multiple is $0$ itself. So
$$f(m) - f(m-n) = 0, \quad \text{i.e.} \quad f(m-n) = f(m).$$

**Finishing.** Substitute this back into the first fact,
$f(m-n) \mid f(m)-f(n)$: since $f(m-n)=f(m)$, this becomes
$$f(m) \mid f(m) - f(n).$$
Since $f(m)$ also (trivially) divides itself, $f(m)$ divides the
difference of these two:
$f(m) \mid \big(f(m) - (f(m)-f(n))\big) = f(m) \mid f(n)$.

$\blacksquare$

One honest note on the translation: in the "showing $f(m-n)$ equals
$f(m)$ exactly" step, the Lean proof hedges with a `first | ... | ...`
between two different tactic approaches to that same sub-claim (one via a
direct "a divisor smaller in absolute value than the bound is zero"
lemma, one via an explicit case split on the divisor's sign) — both prove
the identical statement, so the prose above reflects the *claim*, which
is the same either way, not the specific tactic machinery used to
discharge it.
